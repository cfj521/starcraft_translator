# 实机 e2e 验收清单（Phase 2 / 4 / 5 / 6 合并）

> 用法：开《星际争霸：重制版》（**窗口化/无边框**，独占全屏会盖住悬浮窗）→ 按项操作 → 在"结果"栏标 ✅/❌/⚠️。
> 失败项请附 `logs/app.log`（发布版在 exe 同目录 logs/ 下）对应时间段，回来贴给我即可定点排查。
> 版本：`phase4-multiregion-ui` @ Phase 5-7（0.4.0）。

## 0. 准备（一次性）

## 4. Phase 6：场景识别（图像指纹）

> 面板看 `指纹:` 那一行——它列出每个参考条目各命中多少百分比，是排查"识别不对"的第一现场。

| # | 操作 | 预期 | 结果 |
|---|------|------|------|
| 4.1 | 站自定义游戏列表，按 F8 开面板 | "场景: 寻找房间"；`browsing 100%`，其余 ≤30% | |
| 4.2 | 进入某个房间（等待大厅） | 1~2 秒内切"房间内"（日志 `[scene] 切换 …`），`room 100%` | |
| 4.3 | 开局进对局 | 切"游戏内·人族/神族/虫族"，种族与自己实际种族一致 | |
| 4.4 | 对局中选中单位、拖视野、造兵（画面剧变） | **仍稳定判"游戏内"**不掉档（装饰板是静态的，视口不参与判定） | |
| 4.5 | 对局中退到主菜单/看加载画面 | 约 3 秒后判"其他界面"：悬浮清空、停止翻译、日志不再催校准 | |
| 4.6 | 从主菜单回到房间列表 | 自动切回"寻找房间"并恢复翻译（无需重启）。**关键回归**：`其他界面`/`无 ROI 的未校准场景` 都不能是"只进不出"的死状态——进去后识别必须仍在跑，否则永远回不来（曾犯：识别被挡在 `_roiAvailable` 判断之后） | |
| 4.7 | 把游戏分辨率改成没做过参考的值 | 日志 `[scene] 参考不可用：…当前分辨率…`；**保持原场景继续翻**，不硬猜 | |
| 4.8 | 临时改名 exe 旁 `scene-refs.json` 后重启 | 日志 ERROR"场景参考不可用"；翻译上不来（预期），改回即恢复 | |
| 4.9 | 手改 `scene-refs.json` 里任一数字（如某个 rect）后重启 | sha256 校验不通过 → 整份拒用并报"请用 tools/SceneRefGen 重新生成"（证明该文件不可手改） | |

> 这一节验的是"不靠校准也能翻（预设唯一来源）"和"DEBUG 校准改得动预设"。区域在 配置→区域 页看（仅 DEBUG 模式）。

| # | 操作 | 预期 | 结果 |
|---|------|------|------|
| 5.1 | 全新安装（预设出厂）直接进寻找房间，按 F9 | **不校准也能翻**：聊天与房间名/地图名出中文。区域页（DEBUG）显示 4 条预设 part | |
| 5.2 | 游戏没开时按 Ctrl+F9 | 日志 `[app] 无法校准：未找到游戏窗口（进程 …）`，**不进校准** | |
| 5.3 | 游戏在后台/最小化时按 Ctrl+F9 | 分别提示"不在前台"/"已最小化"，不进校准 | |
| 5.4 | 游戏在前台按 Ctrl+F9（DEBUG 模式） | 顶部显示 `场景【X】 · 分辨率 WxH`；X 与你**实际所在界面**一致（哪怕从没按过 F9）；画面上是**彩色边框的预设编辑框**（可选中/平移/拖角缩放） | |
| 5.5 | `DebugMode=false`（F8 未开）按 Ctrl+F9 | **校准窗不打开**（日志 `[app] 校准仅 DEBUG 模式可用`），验证门控 | |
| 5.6 | 拖一个预设框（整框平移 / 拖角改大小） | 框实时跟随，不许缩成线；Enter 保存**直写**出厂 `layout-presets.json`（无覆盖层） | |
| 5.7 | 配置→区域：双击一条预设 part，改坐标后确定 | 弹预设编辑框；保存后**出厂** `layout-presets.json` 被改；**实机立即按新坐标出字**（不需重启，验证 `ReloadLayoutPresets` 生效） | |
| 5.8 | 选中预设 part 点"删除选中" | 该 part 被删（置 null 持久化），该区域不再翻译 | |
| 5.9 | 校准一条并 Enter 保存 | 写进**当前检测到的场景**的预设（不是永远落 browsing）；运行中探测立即生效 | |
| 5.10 | 跑 `dotnet run --project tools/LayoutCheck -- "docs/scenes pictures/browsing-4.png"` | 把预设 part 画到截图上，像素坐标与实机一致（同一套 `Parts()` 换算） | |

## 已知边界（不算失败）

- 玩家 ID 开启翻译后是"音译/乱译"——专有名词本无标准译法，默认关是对的。
- 独占全屏：悬浮窗被游戏盖住——软件不解决，只能窗口化运行（README 约束）。
- 分辨率切换后不重校准的位置偏差——等比映射兜底，日志已提示。
- 开发版"开机自启"指向 bin\Debug 路径——发布版才有意义。
