# 实机 e2e 验收清单（Phase 2 / 4 / 5 / 6 合并）

> 用法：开《星际争霸：重制版》（**窗口化/无边框**，独占全屏会盖住悬浮窗）→ 按项操作 → 在"结果"栏标 ✅/❌/⚠️。
> 失败项请附 `logs/app.log`（发布版在 exe 同目录 logs/ 下）对应时间段，回来贴给我即可定点排查。
> 版本：`phase4-multiregion-ui` @ Phase 5-7（0.4.0）。

## 0. 准备（一次性）

| # | 步骤 | 预期 | 结果 |
|---|------|------|------|
| 0.1 | 启动 `ScrTranslator.App.exe`（发布版或 `dotnet run`） | 无窗口弹出（托盘应用）；托盘出现图标；日志有 6 行 `[hotkey] 注册 *=True` | |
| 0.2 | 托盘右键 → 配置… | 配置窗打开，6 页+关于；关于页显示版本 0.4.0.x | |
| 0.3 | 翻译页 provider 池：各行的「配置…」填各家密钥/登录（腾讯/阿里云 MT 填 SecretId/SecretKey、AccessKey/Secret；ChatGPT 登录；DashScope 填 Key） | 密钥存 SecretStore(DPAPI)；ChatGPT 走浏览器 OAuth 后可用态变"已登录"；可拖拽排序、每行启用/禁用 | |
| 0.4 | 进游戏自定义房间列表界面 → F10 校准 → 框住房间列表（类型 RoomList）→ 划列（ID/房间名/地图）→ Enter 存盘 | 校准窗可拖框/命名/划列；保存后无需重启即生效（热重载日志 `ROI 已重新加载`） | |

## 4. Phase 6：场景识别（图像指纹）

> 面板看 `指纹:` 那一行——它列出每个参考条目各命中多少百分比，是排查"识别不对"的第一现场。

| # | 操作 | 预期 | 结果 |
|---|------|------|------|
| 4.1 | 站自定义游戏列表，按 F8 开面板 | "场景: 寻找房间"；`browsing 100%`，其余 ≤30% | |
| 4.2 | 进入某个房间（等待大厅） | 1~2 秒内切"房间内"（气泡提示），`room 100%` | |
| 4.3 | 开局进对局 | 切"游戏内·人族/神族/虫族"，种族与自己实际种族一致 | |
| 4.4 | 对局中选中单位、拖视野、造兵（画面剧变） | **仍稳定判"游戏内"**不掉档（装饰板是静态的，视口不参与判定） | |
| 4.5 | 对局中退到主菜单/看加载画面 | 约 3 秒后判"其他界面"：悬浮清空、停止翻译、日志不再催校准 | |
| 4.6 | 从主菜单回到房间列表 | 自动切回"寻找房间"并恢复翻译（无需重启）。**关键回归**：`其他界面`/`无 ROI 的未校准场景` 都不能是"只进不出"的死状态——进去后识别必须仍在跑，否则永远回不来（曾犯：识别被挡在 `_roiAvailable` 判断之后） | |
| 4.7 | 把游戏分辨率改成没做过参考的值 | 气泡"当前分辨率缺少场景识别参考…"；**保持原场景继续翻**，不硬猜 | |
| 4.8 | 临时改名 exe 旁 `scene-refs.json` 后重启 | 日志 ERROR"场景参考不可用"；翻译上不来（预期），改回即恢复 | |
| 4.9 | 手改 `scene-refs.json` 里任一数字（如某个 rect）后重启 | sha256 校验不通过 → 整份拒用并报"请用 tools/SceneRefGen 重新生成"（证明该文件不可手改） | |

## 已知边界（不算失败）

- 玩家 ID 开启翻译后是"音译/乱译"——专有名词本无标准译法，默认关是对的。
- 独占全屏：悬浮窗被游戏盖住——软件不解决，只能窗口化运行（README 约束）。
- 分辨率切换后不重校准的位置偏差——等比映射兜底，气泡已提示。
- 开发版"开机自启"指向 bin\Debug 路径——发布版才有意义。
