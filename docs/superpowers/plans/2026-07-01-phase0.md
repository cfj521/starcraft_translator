# Phase 0 工程骨架 + 透明置顶悬浮窗 — 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 搭建 .NET 10 三工程骨架，做出一个透明、置顶、点击穿透、显示一行中文的 WPF 悬浮窗，并带系统托盘（显隐/退出）。

**Architecture:** `ScrTranslator.App`(WPF) 负责 UI/启动/托盘，依赖 `ScrTranslator.Core`(无 UI 业务逻辑)；`ScrTranslator.Core.Tests`(xUnit) 对 Core 单测。点击穿透位运算抽到 Core 做 TDD，P/Invoke 调用留在 App。启动用 `Microsoft.Extensions.Hosting` + DI 组织。

**Tech Stack:** .NET 10 (net10.0-windows10.0.19041.0)、WPF、H.NotifyIcon.Wpf 2.4.1、Microsoft.Extensions.Hosting、xUnit。

参考 spec：`docs/superpowers/specs/2026-07-01-phase0-design.md`

## Task 2: Core 点击穿透位运算（TDD）

**Files:** Test `tests/ScrTranslator.Core.Tests/WindowStylesTests.cs`；Create `src/ScrTranslator.Core/Interop/WindowStyles.cs`

- [ ] **Step 1: 写失败测试**

创建 `tests/ScrTranslator.Core.Tests/WindowStylesTests.cs`：

```csharp
using ScrTranslator.Core.Interop;
using Xunit;

namespace ScrTranslator.Core.Tests;

public class WindowStylesTests
{
    [Fact]
    public void ApplyClickThrough_SetsTransparentAndLayeredBits()
    {
        int result = WindowStyles.ApplyClickThrough(0);
        Assert.Equal(
            WindowStyles.WS_EX_TRANSPARENT | WindowStyles.WS_EX_LAYERED,
            result);
    }

    [Fact]
    public void ApplyClickThrough_PreservesExistingBits()
    {
        const int existing = 0x00000008; // WS_EX_TOPMOST
        int result = WindowStyles.ApplyClickThrough(existing);

        Assert.Equal(existing, result & existing);
        Assert.True((result & WindowStyles.WS_EX_TRANSPARENT) != 0);
        Assert.True((result & WindowStyles.WS_EX_LAYERED) != 0);
    }

    [Fact]
    public void ApplyClickThrough_IsIdempotent()
    {
        int once = WindowStyles.ApplyClickThrough(0x40);
        int twice = WindowStyles.ApplyClickThrough(once);
        Assert.Equal(once, twice);
    }

    [Fact]
    public void RemoveClickThrough_ClearsBitsButKeepsOthers()
    {
        const int other = 0x00000008; // WS_EX_TOPMOST
        int applied = WindowStyles.ApplyClickThrough(other);
        int removed = WindowStyles.RemoveClickThrough(applied);
        Assert.Equal(other, removed);
    }
}
```

```csharp
namespace ScrTranslator.Core.Interop;

/// <summary>
/// Win32 扩展窗口样式中与"点击穿透"相关的位及其计算（纯逻辑，可单测）。
/// 实际的 GetWindowLong/SetWindowLong 调用在 App 层完成。
/// </summary>
public static class WindowStyles
{
    public const int WS_EX_TRANSPARENT = 0x00000020;
    public const int WS_EX_LAYERED = 0x00080000;

    /// <summary>在已有扩展样式上叠加点击穿透所需位；幂等。</summary>
    public static int ApplyClickThrough(int exStyle)
        => exStyle | WS_EX_TRANSPARENT | WS_EX_LAYERED;

    /// <summary>移除点击穿透位（为后续校准模式预留）。</summary>
    public static int RemoveClickThrough(int exStyle)
        => exStyle & ~(WS_EX_TRANSPARENT | WS_EX_LAYERED);
}
```

Run: `dotnet test tests/ScrTranslator.Core.Tests`

> P/Invoke 依赖真实窗口句柄，不做单测；通过编译 + Task 7 手动验收覆盖。

- [ ] **Step 1: 写 NativeMethods**

创建 `src/ScrTranslator.App/Interop/NativeMethods.cs`：

```csharp
using System;
using System.Runtime.InteropServices;
using ScrTranslator.Core.Interop;

namespace ScrTranslator.App.Interop;

/// <summary>user32 互操作：把窗口设为点击穿透。</summary>
internal static class NativeMethods
{
    private const int GWL_EXSTYLE = -20;

    // 64 位 Windows 使用 *Ptr 版本（本项目仅支持 64 位 Windows 10/11）。
    [DllImport("user32.dll", SetLastError = true, EntryPoint = "GetWindowLongPtrW")]
    private static extern IntPtr GetWindowLongPtr(IntPtr hWnd, int nIndex);

    [DllImport("user32.dll", SetLastError = true, EntryPoint = "SetWindowLongPtrW")]
    private static extern IntPtr SetWindowLongPtr(IntPtr hWnd, int nIndex, IntPtr dwNewLong);

    /// <summary>给窗口加上 WS_EX_TRANSPARENT | WS_EX_LAYERED，使鼠标事件穿透到下层。</summary>
    public static void EnableClickThrough(IntPtr hwnd)
    {
        int exStyle = (int)GetWindowLongPtr(hwnd, GWL_EXSTYLE);
        int newStyle = WindowStyles.ApplyClickThrough(exStyle);
        SetWindowLongPtr(hwnd, GWL_EXSTYLE, new IntPtr(newStyle));
    }
}
```

```csharp
using System;
using System.Windows;
using System.Windows.Controls;
using System.Windows.Media;
using H.NotifyIcon;

namespace ScrTranslator.App.Services;

/// <summary>系统托盘图标：显隐悬浮窗、退出。</summary>
public sealed class TrayService : IDisposable
{
    private readonly OverlayWindow _overlay;
    private TaskbarIcon? _trayIcon;

    public TrayService(OverlayWindow overlay) => _overlay = overlay;

    public void Initialize()
    {
        var toggleItem = new MenuItem { Header = "显示/隐藏悬浮窗" };
        toggleItem.Click += (_, _) => ToggleOverlay();

        var exitItem = new MenuItem { Header = "退出" };
        exitItem.Click += (_, _) => Application.Current.Shutdown();

        var menu = new ContextMenu();
        menu.Items.Add(toggleItem);
        menu.Items.Add(new Separator());
        menu.Items.Add(exitItem);

        _trayIcon = new TaskbarIcon
        {
            ToolTipText = "星际翻译",
            IconSource = new GeneratedIconSource
            {
                Text = "译",
                Foreground = Brushes.White,
            },
            ContextMenu = menu,
        };
        _trayIcon.ForceCreate();
    }

    private void ToggleOverlay()
    {
        if (_overlay.IsVisible)
            _overlay.Hide();
        else
            _overlay.Show();
    }

    public void Dispose()
    {
        _trayIcon?.Dispose();
        _trayIcon = null;
    }
}
```

```csharp
using System.Windows;
using Microsoft.Extensions.DependencyInjection;
using Microsoft.Extensions.Hosting;
using ScrTranslator.App.Services;

namespace ScrTranslator.App;

public partial class App : Application
{
    private IHost? _host;
    private TrayService? _trayService;

    protected override void OnStartup(StartupEventArgs e)
    {
        base.OnStartup(e);

        var builder = Host.CreateApplicationBuilder();
        builder.Services.AddSingleton<OverlayWindow>();
        builder.Services.AddSingleton<TrayService>();
        _host = builder.Build();

        var overlay = _host.Services.GetRequiredService<OverlayWindow>();
        overlay.Show();

        _trayService = _host.Services.GetRequiredService<TrayService>();
        _trayService.Initialize();
    }

    protected override void OnExit(ExitEventArgs e)
    {
        _trayService?.Dispose();
        _host?.Dispose();
        base.OnExit(e);
    }
}
```
