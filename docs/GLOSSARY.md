## 7. 翻译规则约定（给 LLM 的提示）
- 玩家 **ID / 昵称 / 纯英文缩写 / 数字**：不翻译，原样保留。
- 聊天口语化、简短，保留游戏语气（如 `ㅋㅋ`→"哈哈"而非"呵呵呵呵"）。
- 上表条目优先级最高，命中即用。
- 不确定的黑话宁可直译 + 保留原文，不要乱编。
