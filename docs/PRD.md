# PRD — SC:R 实时翻译软件产品需求文档

| 项 | 内容 |
|----|------|
| 产品名 | SC:R Translator（暂定） |
| 版本 | v0.1（设计稿） |
| 日期 | 2026-06-30 |
| 平台 | Windows 10 1803+ / Windows 11 桌面 |
| 形态 | 独立桌面软件（.NET 10 LTS + WPF） |

---

## 1. 背景与目标

《星际争霸：重制版》(StarCraft: Remastered) 韩服/国际服活跃度高，联机时大量内容为**韩文**：对战聊天、战网房间名、玩家 ID、地图信息等。中文玩家看不懂，影响交流与游戏体验。

虽然 SC:R **官方内置简体中文 UI**，但**不会翻译"其他玩家产生的动态内容"**（聊天、房间名等）。本产品填补这一空白。

**目标**：提供一个轻量、低延迟、即开即用的实时屏幕翻译工具，把游戏画面里的韩文实时翻成中文，悬浮显示，不修改任何游戏文件。

**非目标（首版不做）**：
- 不做静态汉化（不改游戏文件 / CASC）。
- 不做日/英等其它源语言（首版仅韩→中，但架构上预留多语言）。
- 不做语音翻译。
- 不做反向（中→韩）输入翻译。

---

## 2. 用户与场景

**目标用户**：玩 SC:R 韩服/国际服、看不懂韩文的中文玩家。

**核心场景**：

| # | 场景 | 翻译对象 | 文本特征 |
|---|------|----------|----------|
| S1 | 对战 / 房间内聊天 | 聊天框韩文消息 | 动态、刷新快、含大量游戏黑话缩写 |
| S2 | 战网房间列表 | 房间名 | 半静态，列表滚动 |
| S3 | 战网房间列表 | 玩家 ID | **不翻译**（专有名词，原样显示） |
| S4 | 房间 / 地图信息 | 地图名、地图说明里的韩文 | 半静态 |

## 3. 功能需求 (FR)

### 3.1 捕获与识别
- **FR-1** 自动定位并捕获 SC:R 游戏窗口画面（按窗口句柄，非全屏）。
- **FR-2** 支持用户**框选若干区域(ROI)**并命名（如"聊天框""房间列表""地图信息"），按分辨率保存配置。
- **FR-3** 对每个区域做**变化检测**，画面/文本未变化时不重复 OCR 与翻译。
- **FR-4** 对区域内韩文做 OCR，输出文本（含位置）。

### 3.2 翻译
- **FR-5** 韩文 → 中文翻译，采用**两级**策略：
  - 快引擎（Papago/百度等）先返回结果，悬浮窗以"临时态"显示；
  - LLM（Claude + 术语表）返回后，**原地替换**为高质量结果。
- **FR-6** 内置**术语表**（见 GLOSSARY.md），命中条目直接走本地映射，不走网络。
- **FR-7** **翻译缓存**：同一原文短期内只翻译一次。
- **FR-8** 区分翻译策略：聊天/房间名/地图信息可分别开关翻译；玩家 ID 列翻译与否由**配置项"翻译玩家 ID"控制（默认关闭）**，并可用热键随时切换。

### 3.5 界面与配置
- **FR-16** 提供配置窗口（多标签页：常规/翻译/OCR/区域/热键/外观），详见 [UI_DESIGN.md](UI_DESIGN.md)。
- **FR-17** 常用功能配全局热键（开关翻译、显隐悬浮层、校准、打开配置、切换"翻译玩家 ID"、暂停），可自定义。

### 3.3 悬浮显示
- **FR-9** 透明置顶悬浮窗显示中文译文，**点击穿透**（不抢游戏输入焦点）。
- **FR-10** 译文显示在对应区域旁/内，支持显示原文+译文双行（可配置）。
- **FR-11** 临时态译文（快引擎）与最终态（LLM）有视觉区分（如灰→正常色）。
- **FR-12** 聊天采用**滚动列表**形式，保留最近 N 条历史译文。

### 3.4 控制与设置
- **FR-13** 全局热键：开/关翻译、显示/隐藏悬浮层、进入校准模式。
- **FR-14** 设置界面：API Key、翻译引擎选择、字体/字号/透明度、轮询频率、区域管理。
- **FR-15** 配置持久化（区域、热键、API Key 本地加密存储）。

---

## 4. 非功能需求 (NFR)

- **NFR-1 延迟**：单条聊天从出现到显示快引擎译文 ≤ 1.5s；LLM 最终态 ≤ 4s。
- **NFR-2 性能**：空闲（无新文本）CPU 占用低；不显著影响游戏帧率。
- **NFR-3 鲁棒性**：游戏窗口移动/最小化/切换分辨率不崩溃，自动恢复。
- **NFR-4 隐私**：API Key 本地加密存储；除翻译请求外不上传数据。
- **NFR-5 易用**：首次使用有引导（提示窗口化运行 + 区域校准）。
- **NFR-6 可扩展**：OCR 引擎、翻译引擎均可插拔；源/目标语言可扩展。

## 6. 验收标准（v0.1）

1. SC:R 以无边框窗口运行时，悬浮窗能稳定浮在游戏上且不抢焦点。
2. 在房间内发一条韩文聊天，3 秒内悬浮显示通顺中文译文。
3. 房间列表中房间名/地图信息被翻译，玩家 ID 默认保持原样；开启"翻译玩家 ID"(或按 F7)后 ID 也被翻译。
4. 常见游戏黑话（如 `ㅋㅋ`、`gg`、`러시`）翻译准确（命中术语表）。
5. 切换游戏分辨率后，重新校准一次即可正常工作。

## 7. 主要风险

| 风险 | 影响 | 缓解 |
|------|------|------|
| 独占全屏盖住悬浮窗 | 不可用 | 引导用户用窗口化/无边框；检测并提示 |
| OCR 对韩文小字/花体识别差 | 翻译质量 | 区域裁剪+预处理；Windows OCR→PaddleOCR 升级 |
| 游戏黑话翻译烂 | 体验差 | LLM + 术语表 + 上下文提示 |
| 聊天刷新快，OCR/翻译跟不上 | 漏译 | 变化检测+缓存+异步队列+两级 |
| 反作弊/封号顾虑 | 用户流失 | 纯读屏不注入游戏进程、不改文件、不读内存，风险低；文档说明 |
